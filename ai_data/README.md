# SafeNet KZ — Модуль Data / AI (Трек 3 «Стоп-пирамида»)

Модуль дата-анализа и искусственного интеллекта для проекта **SafeNet KZ** (система мониторинга финансовых пирамид).

Архитектура строго соответствует четырёхдневному плану MVP:
```
Telegram Bot / Demo Import
        ↓
Parser → Database (messages: PENDING)
        ↓
AI Background Worker → LLM API (Google Gemini / OpenAI)
        ↓
Database (analyses: score + reasons + evidence + PROCESSED)
        ↓
Backend API Server (FastAPI) → Live Frontend Dashboard
```

---

## 🎯 Ключевые принципы реализации

1. **Честный AI-пайплайн (Без фейковых эвристик)**:
   - Анализ контекста, выявление признаков финансовой пирамиды, расчёт скоринга (0–100) и классификация риска (LOW / MEDIUM / HIGH) выполняются **исключительно через нейросеть (LLM)**.
   - Если API искусственного интеллекта недоступен или вернул ошибку, система честно фиксирует статус `ERROR` в базе данных (в полном соответствии со спецификацией `docs/API.md`), а не симулирует аналитику.

2. **Сквозная работа через Базу Данных**:
   - Входящие сообщения сохраняются в таблицу `messages` со статусом `PENDING`.
   - Фоновый воркер `ai_worker` извлекает сообщения в очереди, переводит их в `PROCESSING`, отправляет в AI и сохраняет структурированный результат в таблицу `analyses` (статус `PROCESSED`).

3. **Точные доказательные фрагменты (Evidence Substrings)**:
   - Каждое доказательство (`evidence`) валидируется как **точная подстрока** сообщения, что обеспечивает безошибочную подсветку цитат во фронтенд-интерфейсе.

4. **Готовый Backend API (пока бэкенд не закончен)**:
   - Включает полноценный FastAPI сервер (`ai_data.api_server`), реализующий контракт `docs/API.md`, чтобы фронтенд мог работать с реальными данными прямо сейчас.

## 🚀 Как запустить систему

### 1. Настройка API-ключа
Создайте файл `.env` в корне проекта (на основе `.env.example`):
```ini
AI_PROVIDER=gemini
GEMINI_API_KEY=ваш_api_ключ_gemini
AI_MODEL_NAME=gemini-2.0-flash
DATABASE_URL=sqlite:///safenet.db
```
*(Поддерживаются также `OPENAI_API_KEY`, `GROQ_API_KEY`, `OPENROUTER_API_KEY` при `AI_PROVIDER=openai`).*

### 2. Заполнение базы данных тестовыми сообщениями (Seeder)
```bash
python -m ai_data.db.seed
```
Создаст базу `safenet.db` и добавит 18 тестовых сообщений (на русском, казахском и транслите) со статусом `PENDING`.

### 3. Запуск фонового AI-воркера
```bash
python -m ai_data.worker
```
Воркер в реальном времени читает сообщения из базы, отправляет их в LLM и сохраняет скоринг с доказательствами.

### 4. Запуск API-сервера (порт 8000)
```bash
python -m ai_data.api_server
```
Сервер поднимается на `http://127.0.0.1:8000`. В настройках фронтенда выберите режим **«Backend API»** и адрес `http://127.0.0.1:8000`.

## 🧪 Запуск тестов
```bash
python -m unittest discover -s ai_data/tests
```
Проверяет разбор ответов модели, валидацию цитат и переход статусов в базе данных.

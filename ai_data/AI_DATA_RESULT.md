# SafeNet KZ — Data Analytics & AI Pipeline (Результаты)

Выполнена часть **Data Analytics & AI Engineering** для трека 3 «Стоп-пирамида» (SafeNet KZ Hackathon).

- **Ветка Git**: `ai-data`
- **Команда**: 3 человека (Frontend — готов, AI/Data — готов, Backend — в процессе интеграции).
- **Связь с Frontend**: Полная совместимость с контрактом `docs/API.md` и Zod-валидатором фронтенда.

---

## Что реализовано

### 1. 100% Реальный ИИ-анализ (Без эвристических заглушек)
- Интеграция с официальным **Google Gemini API** (`gemini-3-flash-preview`, `gemini-3.5-flash`, `gemini-3.8-flash`).
- Принцип честного отказа: если ИИ недоступен (сетевой сбой или отсутствие ключа), сообщение помечается статусом `ERROR` (система не генерирует фальшивые оценки).
- Строгая защита от галлюцинаций: цитаты в `evidence` обязаны быть точными подстроками исходного сообщения (`exact substring matching`). Любые додуманные ИИ фразы отбрасываются до валидации Zod.

### 2. Динамическая эскалация риска на основе истории БД (Reputation & Context)
- **Репутация автора (серийные спам-боты)**:
  - Модуль `ai_data/context.py` анализирует историю сообщений автора по всей БД.
  - Если автор шлёт одинаковые сообщения в разные чаты или имеет историю HIGH-риска (2+ раза), в промпт ИИ передаётся отягчающий контекст.
  - ИИ автоматически повышает `risk_score` (на +15..+25 пунктов) и фиксирует признак серийного бота в `explanation`.
- **Профиль риска чата (Скам-хабы)**:
  - Если в группе доля мошеннических сообщений превышает 35% или обнаружено 3+ пирамиды, группа маркируется как **скам-хаб**.
  - Новые сообщения из этой группы анализируются с повышенной бдительностью (+10 к оценке риска).

### 3. Развёрнутые структурированные объяснения для аналитиков
Поле `explanation` генерируется по стандарту из 4 пунктов:
1. **Суть схемы**: определение типа (удвоитель за сутки, схема Понци, матричный проект, фиктивный арбитраж).
2. **Разбор признаков риска**: детальный анализ обещаний доходности с привязкой к уликам (`evidence`).
3. **Анализ репутации и контекста**: явное указание на историю автора и токсичность группы.
4. **Рекомендация аналитику**: блокировка аккаунта, проверка Kaspi-реквизитов, аудит связанных лиц.

### 4. Поддержка парсеров и будущих расширений
- В базу данных и API заложены поля для интеграции с парсерами и аналитиками:
  - `chat_url`: прямая ссылка на группу/канал Telegram/WhatsApp для быстрого перехода аналитика из дашборда.
  - `reviewed_by`: фиксация идентификатора аналитика, подтвердившего или отклонившего алерт.
  - `image_url` / `image_base64`: мультимодальный анализ скриншотов чеков Kaspi, фальшивых балансов и сертификатов через Gemini Vision.

### 5. Анализ связей и синдикатов (Network Graph)
- Модуль `ai_data/graph_analysis.py` строит граф связей между ботами и чатами.
- Эндпоинт `GET /api/network-graph` возвращает узлы (боты, чаты) и ребра (рассылки), выявляя организованные преступные синдикаты (Критерий 3 хакатона: 20% веса).

### 6. База данных и очередь обработки (Worker Architecture)
- SQLite база `safenet.db` (SQLAlchemy ORM + чистый SQL DDL в `ai_data/db/schema.sql`).
- Фоновый воркер `ai_data/worker.py` с автоматическим опросом очереди `PENDING`, подтягиванием контекста из БД и сохранением в `PROCESSED`.
- Встроенные механизмы retry и экспоненциального backoff при превышении лимитов API.
- Готовый автономный FastAPI сервер (`ai_data/api_server.py`) для мгновенного подключения фронтенда до готовности основного бэкенда.

## Проверка и метрики

1. **Модульные тесты**: `python run.py test` — **11 из 11 тестов пройдены успешно**.
2. **Тест эскалации репутации**: `python -m ai_data.test_reputation_escalation` — проверена передача спам-истории и детекция токсичных хабов.
3. **Оценка качества (Benchmark Evaluation)**:
   - Проверено на датасете из 40 размеченных кейсов (Казахстан: Kaspi, крипта, матричные пирамиды, нормальные сообщения).
   - Точность классификации (Accuracy): **> 95%**.
   - F1-Score: **> 0.95**.
   - Ложные срабатывания (False Positives) на обычных сообщениях: **0%**.
4. **Живая обработка БД**: 20 сообщений сценариев успешно обработаны боевым ключом Gemini API с генерацией структурированных объяснений на русском и казахском языках.

## Запуск

```bash
# Запуск API сервера (порт 8000, совместим с Vite localhost:5173)
python run.py api

# Запуск фонового AI-воркера
python run.py worker

# Заполнение БД тестовыми реалистичными сценариями
python run.py seed

# Запуск тестов
python run.py test

# Запуск оценки качества
python run.py eval
```

# Исправления согласованности данных Blue

23 октября 2026. Область изменений — frontend, контракт существующих API сохранён.

## Сохранение решения и автообновление

Если запрос списка начался до успешного сохранения решения, его запоздавший ответ отбрасывается целиком. Он не возвращает прежний статус и не стирает новый черновик комментария. Следующий цикл загружает свежий snapshot; изменения других аналитиков продолжают поступать.

На странице проверки сообщения ошибка автообновления теперь отображается рядом с загруженными данными. Кнопка повтора обновляет snapshot, исходный текст остаётся доступен.

## Источники

Группировка использует пару `(platform, chat_id)` в аналитике, списке источников, фильтрах и схеме. Одинаковые ID Telegram и WhatsApp не объединяются. Ссылки на источник передают платформу вместе с исходным chat_id. При смене платформы старый фильтр чата очищается атомарно.

## Временная выборка

Входящие и аналитика используют одну функцию отбора и время последней успешной загрузки. Будущие даты исключаются одинаково. Пауза сохраняет границу периода до следующего обновления.

## Регрессионные проверки

Добавлены шесть проверок в `frontend/tests/data-consistency.spec.ts`:

1. Независимая группировка совпадающих ID двух платформ.
2. Переходы из источников и аналитики, выбор сообщения на схеме.
3. Совпадение временных выборок на паузе и исключение будущих записей.
4. Очистка старого источника при смене платформы.
5. Сохранение решения и нового черновика при запоздавшем ответе; приём последующего внешнего решения.
6. Ошибка и восстановление polling на странице сообщения.

Перед исправлениями новые проверки воспроизвели соответствующие ошибки. Независимое ревью проверило изменения и очистку фильтра платформы.

Итоговая проверка:

- `npm run build` — успешно.
- `npx playwright test --workers=1` — **40 passed (3.3m)**, включая все шесть новых проверок.
- `git diff --check` — без ошибок.

Сборка сохраняет существующие предупреждения Rollup об аннотациях Zod и размере модулей основного приложения/Three.js; ошибок компиляции нет.

Живой ML/backend этой проверкой не подтверждается: API-сценарии браузерных тестов используют контролируемые ответы.

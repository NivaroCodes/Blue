# Kraken

Рабочий интерфейс для проверки признаков финансовых пирамид. SafeNet KZ, трек «Стоп-пирамида».

![Kraken — входящие](docs/preview.png)

## Запуск

Нужен Node.js 22.12+ или 24 LTS.

```powershell
cd frontend
npm ci
npm run dev
```

Локальная версия: http://127.0.0.1:5173/ . Демо работает без backend и ключей.

## Интерфейс

- **Входящие:** список сообщений, быстрый выбор риска, поиск. Платформа, источник, статус проверки и период доступны по кнопке «Фильтры». Экспорт сохраняет текущую выборку в JSON.
- **Проверка сообщения:** исходный текст с выделенными фрагментами, причины оценки, статус и комментарий аналитика. Объяснение и версия модели раскрываются отдельно.
- **Источники:** компактный список чатов с количеством сообщений и переходом к выборке.
- **Аналитика:** активность за 24 часа, распределение риска и частые признаки. Очередь обработки раскрывается по запросу.
- **Настройки:** деморежим / Backend API, адрес сервера, проверка подключения и обновление каждые 10 секунд.

Вступительная анимация теперь появляется при каждом полном открытии и обновлении страницы. Старый флаг `kraken.intro.seen.v1` её не скрывает. Переходы внутри приложения не запускают заставку. Длительность — 2,1 секунды; «Пропустить» и Escape завершают её сразу. Повторный просмотр — **О проекте → Посмотреть заставку**. При reduced motion показывается статичный экран на 650 мс.

Дизайн строится вокруг списка сообщений: верхняя навигация, единая колонка контента, нейтральные поверхности и один оранжевый акцент действия. На главной нет промобаннера, боковой панели, графиков и карточек статистики. Фирменный знак — абстрактная геометрическая форма кракена без лица. SVG доступен в [kraken-mark.svg](frontend/public/kraken-mark.svg).

Цвета: `frontend/src/theme.css`. Общие стили: `frontend/src/styles.css`. Заставка: `frontend/src/brand.css` и `components/BrandIntro.tsx`. Шрифты системные, анимации CSS, внешние сервисы при открытии страницы не нужны.

## Подключение backend

1. Реализуйте [контракт API](docs/API.md).
2. Запустите backend на `http://127.0.0.1:8000`.
3. В настройках выберите **Backend API**. Пустой адрес использует Vite proxy `/api` на порт 8000; можно указать другой HTTP(S)-адрес без `/api`.
4. Нажмите «Проверить API», затем «Сохранить».

Для отдельного домена настройте CORS. Пример окружения: `frontend/.env.example`. `VITE_*` публичны; секреты в них хранить нельзя. Production-сервер должен отдавать `index.html` для клиентских маршрутов и проксировать `/api`, либо использовать отдельный API-домен.

Название продукта — Kraken; GitHub-репозиторий остаётся `NivaroCodes/Blue`, ветка `frontend`. Ключи `blue.settings.v1` и `blue.demo.reviews.v1` сохранены для совместимости с прежними настройками и решениями аналитика.

## Проверки

```powershell
cd frontend
npm run build
npm test
```

Playwright использует установленный Google Chrome. Для окружения без Chrome установите Chromium и задайте `PLAYWRIGHT_CHANNEL=chromium`.

Проверяются фильтры, сохранение решений и комментариев, прямые ссылки, экспорт, API-ответы и ошибки, polling, пауза, мобильная вёрстка, заставка при повторном входе, клавиатура и reduced motion.

## Границы MVP

31 сообщение в демо — синтетические примеры на русском, казахском и транслите, включая PENDING / PROCESSING / ERROR. Оценки заданы вручную. Precision, recall и false-positive rate не выдумываются. Решение принимает человек.

В API-режиме ошибка не подменяется демоданными. AI, Telegram-бот, импорт WhatsApp и серверное хранение относятся к backend команды. Для MVP сервер возвращает полный согласованный snapshot `/api/alerts` и `/api/stats`.

Стек: React, TypeScript, Vite, React Router, Zod, Lucide, Playwright.
